# 私有推送断线保护验收（2026-09-20 UTC）

## 本轮范围

- 账户与原生保护单两路连接均需已配置、连接且认证；任一路缺失或状态未知不放行新开仓。
- 执行器在预检前、预检后、杠杆准备后核验，覆盖网页、Worker 和 TradingView 共用入口。
- 等待告警不等待拦截。Dry Run、既有订单幂等回查及平仓保留各自原有语义，不解除急停、
  执行开关、持仓证据或原生保护校验。
- 独立健康任务不依赖 REST 对账完成；连接、认证、断开会唤醒检查。
- 默认持续断线 30 秒后尝试一次 PushPlus 通知，恢复尝试一次通知；去重仅限当前进程的一次故障。
  发送失败保留脱敏审计，不自动逐次重发；未配置 PushPlus 不误记为通知失败。
- 网页缺少新状态字段也禁止开仓。若原有账户、行情、安全条件满足而保护单流不就绪，
  显示“仅可平仓”；实际平仓按钮在分析渲染、状态推送和可用性刷新后保持一致。
