# 网页只读连接检测验收（2026-09-20）

## 功能范围

“风控与连接 → 账户连接检测”只向管理员开放。服务端使用已有环境配置，
创建独立临时连接，检测两路私有 WebSocket 认证和七项 REST 查询。
不读取浏览器输入的交易所凭据，不复用或停止交易引擎的连接，不发送订单。
网页入口仅允许 OKX Demo；命令行现有显式只读实盘检测参数保持兼容。

一次只运行一项检测，工作超时为 45 秒。检测连接清理完成前不发布成功结果。
私有 SSE 推送进度，输出只含状态、时间和记录数，不含余额、委托详情、密钥、
代理地址或供应商原始错误。结果仅保存在当前进程内，重启后重置。
断线、退出管理员和页面隐藏时清除浏览器结果，迟到响应不能覆盖新推送。
畸形结果、缺少认证证据或查询数量不一致的结果不能显示“只读连接通过”。

## 本机验证

- 完整 API 回归：`unittest discover -s services/api/tests -q`，776 项通过。
- Node 实时与外观回归：14 项通过，包含新脚本的 Docker 构建上下文检查。
- 浏览器：63 个路由检查、11 项新面板交互检查、10 组尺寸/主题检查。
- 真实浏览器到本机 API 子进程，再到回环交易所协议服务：管理员登录、
  点击检测、九项通过、私有 SSE 返回、执行保持关闭。
- 浏览器脚本错误为零；本机交易所协议服务收到的交易变更请求为零。
- 深色/浅色、320/390/768/1024/1440 像素布局检查通过；人工检查电脑和手机截图。

复现命令：

```bash
PYTHONPATH=services/api .venv/bin/python -m unittest discover -s services/api/tests -q
node --test infra/appearance.test.mjs infra/live.test.mjs
.venv/bin/python infra/ui-acceptance.py
```

初始两轮浏览器验收在旧保护事故页面检查阶段出现 CDP 超时，根因尚未确定。
后续一次调试模式和一次正常模式完整通过，没有延长命令超时或跳过旧检查。
测试入口支持 `OPENPERPDESK_UI_TRACE=true` 获取命令序列及卡顿时的浏览器调用栈，
每轮启动前清除旧的成功报告，避免失败运行沿用历史成功证据。
