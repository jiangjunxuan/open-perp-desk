# OpenPerpDesk 界面设计基线

## 设计判断

这是面向交易者和运维人员的中文永续合约后台，不是营销页。视觉方向采用高密度、低干扰的中性炭灰控制台，优先保证状态识别、风险操作和键盘可达性。

## 使用的设计能力

- `taste-skill`：采用反模板、颜色一致、形状一致、按钮对比度、完整加载/空/错状态和改版前审计原则。它明确不针对后台数据表，因此不套用营销页英雄区、装饰性 Bento 卡片或大幅动效。
- `UI-UX-Pro-Max`：采用可访问性优先、桌面和移动响应式、可见焦点、表单显式标签、数据界面高密度和减少动态效果规则。

## 当前设计令牌

- 默认深色背景：`#101113`
- 表面：`#1d1f22` / `#292c30`；工作区底色：`#16181b`
- 主文字：`#f1f2f4`
- 辅助文字：`#a9aeb7`
- 上涨及正常状态：`#51d6a3`；主要操作：`#e8ebee`，文字 `#202329`
- 风险及下跌色：`#ff797f`
- 警告色：`#e9bd67`；信息色：`#a6c8ff`
- 圆角：5px 控件，8px 对话框；页面分区不使用浮动卡片
- 字体：系统中文无衬线；价格及数量使用系统等宽字体和等宽数字
- 动效：仅用于操作反馈和状态变化；支持 `prefers-reduced-motion`

## 交互基线

- 所有输入控件和按钮最小高度为 44px。
- 所有导航和操作控件可通过键盘访问，并保留可见焦点环。
- 私有数据和 Demo 执行继续受管理员令牌、风控和安全闸门约束。
- 加载、失败、空数据和禁用状态必须有明确的文字反馈。
- 不使用 emoji 作为结构化图标，不用颜色作为唯一状态表达。
- 保留已有锚点 ID，并将其用作可直接打开、支持浏览器前进后退的工作视图。

## 本轮页面结构

- 顶部上下文栏：API、环境、时间、模拟盘/实盘和执行锁状态。
- 左侧工作区导航：总览、行情、持仓、订单、成交、策略、风控、运行日志。
- 管理员解锁放在独立原生对话框，支持键盘关闭和焦点返回，令牌不持久化。
- 总览：账户指标、运行状态、自选合约、OHLC K 线、安全闸门和持仓。
- 行情与交易：价格与成交量图、结构化策略、风控预览与订单提交；下方原位切换持仓、委托和成交。
- 策略研究：研究操作、指标、策略参数和自动执行控制。
- 持仓、订单、成交、绩效回测、风控连接、日志分别作为独立视图。
- 分析、回测、PushPlus 测试等命令归属对应视图，急停保留在全局顶栏。

## 交易终端细化

- 侧栏按交易与研究管理分组，保留原有九个路由及主导航文字。
- 收紧交易页标题与顶部控制区，桌面采用左侧行情及交易记录、右侧策略和核验的连续布局。
- 图表支持周期快捷切换、K 线/收盘折线、40/80/100 根可视范围、真实成交量及 OHLC 读数。
- 鼠标指针和左右方向键均可查看 K 线，Home/End 定位首尾，Escape 退出定位。
- 买一、卖一只使用真实 ticker 最优报价，不生成未接入的多档盘口。
- 行情使用服务端 SSE 推送，标记实时、延迟、断线和暂停状态；最新状态按 250ms 合并显示，不将其宣称为无损逐笔行情。
- 交易记录使用可键盘操作的标签页，独立持仓、委托、成交路由继续可用。
- 私有数据空态提供管理员入口；弹窗关闭后返回实际触发按钮。
- 订单核验区区分交易所快照与模拟参数，展示服务器返回的名义价值和敞口。
- 合约、周期、信号或委托输入变化后清除旧核验结果。缺失数值显示 `--`，不能伪装成零。
- 主界面使用中文；合约编码、币种、UTC、API 和项目名称保留行业通用写法。

面板采用无框数据布局和分隔线，不使用营销页 Hero、装饰性渐变或无意义的卡片堆叠。
导航及工具图标来自本地分发的 Lucide 0.468.0，图表标记继续使用相同版本与图标体系，许可证保留在
`apps/web/assets/icons/LICENSE`。重新获取同版本图标运行
`node infra/vendor-icons.mjs`；页面运行时不依赖图标 CDN。

本轮工作台视觉细化记录在
`design-system/openperpdesk/pages/dashboard.md`，用于覆盖全局基线中的
页面级颜色、密度、布局和交互细节；全局 `MASTER.md` 保持不变。

## 后续页面约束

策略配置、代理配置、PushPlus 配置和账户设置页面沿用同一组颜色、半径、焦点和控件尺寸。任何新增页面先补页面级信息架构和空/错/加载状态，再添加视觉装饰。

## 浏览器验收

`infra/ui-smoke.mjs` 对 1440、1024、844 横屏、768、390、375、320px 视口检查真实文档宽度、
画布像素、九个导航视图、深链接、浏览器后退、弹窗焦点和公开行情交互。
新增图表类型/范围/键盘读数、标签页键盘切换、解锁焦点返回、核验结果失效及
工具栏不重叠检查。执行结果写入 `outputs/ui-verification.json`。
移动布局使用 `minmax(0, 1fr)` 限制网格最小宽度，表格的横向滚动
必须保留在自身容器内，不能通过扩大整个页面来容纳内容。手机导航使用原生
模态抽屉，不再依赖九项横向滚动导航。安全面板分别显示
公共行情连接、私有账户事件流和原生止盈止损事件流。

## 工作台精修

- 顶栏、标题与行情工具栏采用更紧凑的垂直节奏，保留 44px 操作热区；右侧交易栏使用连续表面区分操作区域。
- 手机端默认收起市场摘要，图表标题旁提供带 `aria-expanded` 的详情按钮；桌面仍完整展示六项摘要。
- 策略参数使用原生 `fieldset` / `legend` 分为运行模式、技术指标、仓位约束，原有字段 ID 和草稿保持不变。
- 交易记录栏增加独立同步按钮，与账户同步共享加载状态和防重复入口；未解锁时禁用。

- 风控页将连接状态与只读阈值分列，阈值直接读取 `risk_limits`，缺失值显示 `--`，真实零值不丢失。
- 执行状态和提交按钮共用前端闸门判断：执行开关、风险引擎、急停状态、模式和实盘独立解锁必须一致。此处仅用于界面展示与禁用，服务端仍负责最终授权。
- 回归新增窄屏详情展开、图表首屏位置、风控列边界、参数分组、缺失阈值、实盘未解锁和急停的状态一致性检查。

  管理员访问失效时清空已呈现研究，避免延迟响应重新填回。
