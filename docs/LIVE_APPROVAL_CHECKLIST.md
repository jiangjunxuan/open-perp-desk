# 实盘上线前人工审批清单

这份清单是 OpenPerpDesk 从模拟盘进入真实资金环境前的人工闸门。
所有项目必须由审批人逐项确认并保存证据；本地 Mock、CI、页面截图或
`health=200` 不能单独证明真实交易安全。

## 1. 基本信息

- [ ] 服务器、域名、代码版本和镜像 digest 已记录
- [ ] 审批人、复核人、审批时间（含时区）已记录
- [ ] OKX 账户、子账户、账户模式和目标合约范围已记录
- [ ] 回滚版本、最近一次数据库备份路径和校验值已记录
- [ ] 已确认本次只允许使用批准的账户和合约，不使用个人其他账户

## 2. 密钥与访问控制

- [ ] `.env` 权限为 `600`，未进入 Git、镜像层、前端文件、URL 或日志
- [ ] `ADMIN_API_TOKEN` 已改为随机的高强度值，不使用 `admin`、示例值或测试值
- [ ] `LIVE_UNLOCK_PHRASE` 与管理员令牌相互独立，并通过安全渠道保存
- [ ] OKX API Key 仅授予必要权限，不授予提币权限
- [ ] OKX API Key 已限制来源 IP；代理出口 IP 已加入白名单
- [ ] PushPlus token、模型服务密钥和代理认证信息未出现在浏览器或日志
- [ ] 宝塔、HTTPS、管理端口和服务器 SSH 访问已按最小权限配置

## 3. 真实 OKX Demo 验收

- [ ] `OKX_DEMO=true`、`TRADING_MODE=demo`
- [ ] `./infra/openperpdesk.sh private-smoke --timeout 45` 在目标 API 容器内成功，报告时间与本次验收一致
- [ ] 私有 REST 余额、持仓、账户配置、挂单、历史订单和成交数量已核对
- [ ] 私有账户 WebSocket 登录成功并收到账户/持仓/订单事件
- [ ] `orders-algo` WebSocket 登录成功并收到原生保护订单状态
- [ ] 真实 Demo 小额订单完成“提交、部分成交/成交、撤单、对账”闭环
- [ ] 订单状态、成交编号、持仓数量和本地账本逐项一致
- [ ] 真实季度账单文件、UTC 日界线权益观测、出入金和账单覆盖缺口已逐项核对
- [ ] 响应丢失、进程重启和重复请求均证明不会盲目重发
- [ ] 急停触发后新订单被拒绝、实盘闸门回锁；急停期间无法预先解锁，恢复后须重新人工解锁
- [ ] 解锁通知延迟期间发生急停时，返回值和界面仍显示最新的锁定状态

## 4. 实时性与代理

- [ ] `infra/realtime-smoke.py --base-url <实际 HTTPS 地址>` 连续通过
- [ ] 行情、系统和私有 SSE 均无代理缓冲；断线后能显示失联而不是伪造实时
- [ ] OKX 公共 REST、四路 WebSocket 和 PushPlus 通过目标 SOCKS5/HTTP 代理
- [ ] 代理认证失败时系统 fail-closed，且错误信息不泄露认证信息
- [ ] 外层宝塔反向代理已验证 HTTPS、SSE、WebSocket 和 AI 长请求超时
- [ ] 目标服务器时钟同步；记录时区和 UTC 日界线

## 5. 策略、AI 与风控

- [ ] 结构化策略的合约、周期、方向、数量、杠杆和保护参数已人工复核
- [ ] TradingAgents 真实模型服务和外部数据工具已单独验收
- [ ] AI 输出仍为研究结果，不能直接授权下单
- [ ] 风控限额、单日亏损上限、总名义敞口和最小置信度已记录
- [ ] 账户权益、资金费、手续费、待成交敞口和活动保护单均纳入预检
- [ ] 标记价格缺失、过期或异常时策略和本地保护会停判
- [ ] 附带保护创建失败会阻止同合约新开仓并触发告警
- [ ] 原生止盈止损状态、部分成交、减仓和重启恢复已核对

## 6. 通知、备份与恢复

- [ ] PushPlus 真实 token 已测试，微信端实际收到测试通知
- [ ] 测试通知的受理状态和微信收信已分别记录
- [ ] 订单失败、成交、风控拒绝、急停、Worker 异常和私有流断线均有通知策略
- [ ] `./infra/openperpdesk.sh backup` 生成快照和 SHA-256 清单
- [ ] 已在隔离目录验证备份可读，且恢复前自动急停和禁用执行
- [ ] 已演练恢复、回滚、重启和断电后的持久急停状态
- [ ] 恢复后已重新核对账户、订单、成交、持仓和未知提交状态

## 7. 小额实盘批准

- [ ] 以上必需项目均有证据，不存在未解决的关键缺陷或未验收项；签字不能替代验收
- [ ] 实盘配置已核对：

  ```dotenv
  TRADING_MODE=live
  OKX_DEMO=false
  LIVE_TRADING_ENABLED=true
  EXECUTION_ENABLED=true
  AUTO_TRADING_ENABLED=false
  AUTO_TRADING_DRY_RUN=true
  ```

- [ ] 进程启动后 `live_safety.allowed=false`
- [ ] 仅由审批人在当前进程内输入独立解锁短语
- [ ] 首次只允许批准的最小名义金额、单一合约和明确的保护价
- [ ] 首次成交后立即核对订单、成交、持仓、保护单、通知和审计日志
- [ ] 发现任何未知结果、保护缺失、数据失联或账本不一致时立即急停
- [ ] 小额试运行结束后重新锁定实盘并保存完整审计记录

## 8. 审批结论

- [ ] 批准进入小额实盘试运行
- [ ] 仅批准只读/模拟盘，禁止实盘
- [ ] 驳回，整改后重新审批
